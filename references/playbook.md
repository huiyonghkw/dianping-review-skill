# 写作经验（基础版）

每次写评价/笔记前读一遍，写完逐条对照。

状态：**硬规则**（内容检查会拦）· **建议**（内容检查会提醒，不拦）

## 两种内容的效果看什么

- **评价**：页面不显示浏览量。看「优质评价」标识、商家回应、赞、网友评论。
- **笔记**：看浏览、赞、网友评论，赞率 = 赞 / 浏览。
- 「评论（N）」里含商家回应，算网友评论时要减掉。
- 店铺页上的「¥42/人」是店铺整体人均，不是你填的人均，不用来核对。

## 经验

### 1. 正文人均和人均栏填同一个数 · 硬规则

- 做法：以小票为准。正文写区间（50-60）时，人均栏的数必须落在区间内。
- 检查：内容检查「人均一致」，对不上直接拦。

### 2. 笔记结尾提一个读者答得上来的问题 · 建议

- 做法：结尾一句具体问题，问读者的经验而不是问「你觉得呢」。例：「天府公园还有哪段路适合带娃骑？」
- 检查：内容检查「结尾提问」会提醒。

### 3. 同店的评价和笔记要分工，开头卖点不重复 · 建议

- 做法：评价写打分、体验和避雷；笔记换一个评价里没展开的角度（路线、机位、时段、避坑清单）。

### 4. 笔记标题带数字和适合人群 · 建议

- 做法：标题里放一个具体数字（价格、距离、时长）和一个人群词（亲子、情侣、一个人）。

### 5. 评价写满事实 · 建议

- 做法：每段都有价格、时长、距离这类具体数字，评价写到 250–350 字，分项打分给全。
- 检查：内容检查「品类必写」会提醒该品类读者最关心、但正文没写到的信息。

Pro 版的写作经验库会随作者的真实复盘持续更新，每条附发布数据作为证据。
